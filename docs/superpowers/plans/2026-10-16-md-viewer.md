# MD Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A single-file Windows desktop Markdown viewer with a Notepad-like look: theme-aware rendered preview, an edit mode with structural completion and syntax underlines, and live file watching.

**Architecture:** A Qt-free, fully unit-tested `mdviewer/core/` package (encoding, settings, themeservice, filewatch, mdcheck, completion) drives a PySide6 UI layer (`main_window.py`, `preview.py`, `editor.py`, `app.py`). All Windows-specific reads (stat, registry) are injected so core logic stays testable without Qt.

**Tech Stack:** Python 3.12+, PySide6 (Qt 6.5+, `QtWebEngineWidgets`, `windowsvista` style), mistune, Pygments, pytest.

**Spec:** `docs/superpowers/specs/2026-10-16-md-viewer-design.md`

## Global Constraints

- Target: Windows 10/11; runtime Python 3.12+ (dev machine default `python` is 3.14.2, no `py` launcher — Task 1 verifies the PySide6 wheel for 3.14, fallback 3.12/3.13).
- Pin `PySide6 >= 6.5` (Qt `Wave_Underline` support).
- `mdviewer/core/*` and `tests/*` must never import Qt.
- Poll cadences: file watcher 1000 ms; system theme 2000 ms (theme poll runs only in System mode).
- Settings persisted at `%APPDATA%\MDViewer\settings.json` (theme choice, window geometry, preview zoom).
- Save semantics: write buffer exactly as-is (no line-ending conversion) in the encoding detected on open.
- v1 non-goals: multiple documents, printing, cross-file search, default `.md` handler, WYSIWYG, custom CSS/themes, localization, executable packaging.

"""BOM-aware text decoding and save-time encoding for MD Viewer."""

_BOMS = (
    (b"\xef\xbb\xbf", "utf-8-sig"),
    (b"\xff\xfe", "utf-16"),
    (b"\xfe\xff", "utf-16"),
)


def detect(raw_bytes: bytes) -> tuple[str, str]:
    """Decode file bytes to text; return (text, encoding_name)."""
    for bom, name in _BOMS:
        if raw_bytes.startswith(bom):
            return raw_bytes.decode(name), name
    try:
        return raw_bytes.decode("utf-8"), "utf-8"
    except UnicodeDecodeError:
        return raw_bytes.decode("windows-1252"), "windows-1252"


def encode(text: str, name: str) -> bytes:
    """Encode text with the named codec (re-adds BOM for utf-8-sig/utf-16)."""
    return text.encode(name)
```

"""Persistence for MD Viewer user settings (%APPDATA%\\MDViewer\\settings.json)."""

import json
import os
from pathlib import Path

_VALID_THEMES = ("system", "light", "dark")
_ZOOM_MIN = 0.25
_ZOOM_MAX = 3.0
_WINDOW_KEYS = ("x", "y", "width", "height")


def default_path() -> Path:
    appdata = os.environ.get("APPDATA")
    base = Path(appdata) if appdata else Path.home() / ".config"
    return base / "MDViewer" / "settings.json"


def default_settings() -> dict:
    return {"theme": "system", "window": None, "preview_zoom": 1.0}


def _clean_window(value) -> dict | None:
    if not isinstance(value, dict):
        return None
    for key in _WINDOW_KEYS:
        if type(value.get(key)) is not int:
            return None
    return {key: value[key] for key in _WINDOW_KEYS}


def _clean(data) -> dict:
    result = default_settings()
    if not isinstance(data, dict):
        return result
    if data.get("theme") in _VALID_THEMES:
        result["theme"] = data["theme"]
    window = _clean_window(data.get("window"))
    if window is not None:
        result["window"] = window
    zoom = data.get("preview_zoom")
    if isinstance(zoom, (int, float)) and not isinstance(zoom, bool):
        result["preview_zoom"] = float(min(max(zoom, _ZOOM_MIN), _ZOOM_MAX))
    return result


def load(path: Path | None = None) -> dict:
    path = path or default_path()
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return default_settings()
    return _clean(data)


def save(path: Path | None, data: dict) -> None:
    path = path or default_path()
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(_clean(data), indent=2), encoding="utf-8")
```

"""System theme detection for MD Viewer (Windows AppsUseLightTheme DWORD)."""

REGISTRY_PATH = r"Software\Microsoft\Windows\CurrentVersion\Themes\Personalize"
REGISTRY_VALUE = "AppsUseLightTheme"


def read_system_theme(reader) -> str:
    """Return 'light' or 'dark' from a caller-provided DWORD reader.

    Any read failure (missing key, access denied, unexpected value)
    means 'light'.
    """
    try:
        return "light" if int(reader()) == 1 else "dark"
    except Exception:
        return "light"


def system_theme_reader():
    """Return a reader for the real Windows registry (Windows only)."""
    import winreg

    def read():
        key = winreg.OpenKey(winreg.HKEY_CURRENT_USER, REGISTRY_PATH)
        try:
            value, _ = winreg.QueryValueEx(key, REGISTRY_VALUE)
        finally:
            winreg.CloseKey(key)
        return int(value)

    return read
```

### Task 5: `core/filewatch.py` - watcher state machine

**Files:**
- Create: `mdviewer/core/filewatch.py`

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `filewatch.WatchEvent` - str-enum with `UNCHANGED = "unchanged"`, `CHANGED = "changed"`, `MISSING = "missing"` (members compare equal to their plain strings).
  - `filewatch.Watcher(path, stat_fn)` - `stat_fn(path)` must return an object exposing `st_mtime_ns` and `st_size` (e.g. `os.stat`), or raise `FileNotFoundError` when the path is gone; any other `OSError` is treated as a transient stat failure and ignored.
  - `Watcher.poll() -> WatchEvent` - first successful stat baselines and returns `UNCHANGED`; a different `(mtime_ns, size)` returns `CHANGED` once; a transition to missing returns `MISSING` exactly once (later polls while missing return `UNCHANGED`); reappearing returns `CHANGED`; a stat equal to the state registered via `note_write` is suppressed (`UNCHANGED`, expectation cleared).
  - `Watcher.note_write(mtime_ns: int, size: int) -> None` - register the disk state produced by our own save so the next poll does not report a false alarm.

"""File watching state machine for MD Viewer (pure logic, injectable stat)."""

from enum import Enum


class WatchEvent(str, Enum):
    UNCHANGED = "unchanged"
    CHANGED = "changed"
    MISSING = "missing"


class Watcher:
    """Poll a file's (mtime_ns, size) and report transitions.

    stat_fn(path) must return an object exposing st_mtime_ns and st_size
    (e.g. os.stat) or raise FileNotFoundError when the path is gone.
    Other OSError is treated as a transient stat failure and ignored.
    """

    def __init__(self, path, stat_fn):
        self.path = path
        self.stat_fn = stat_fn
        self._last = None
        self._expected = None
        self._was_missing = False

    def poll(self) -> WatchEvent:
        state = self._stat()
        if state is None:
            if self._was_missing or self._last is None:
                return WatchEvent.UNCHANGED
            self._was_missing = True
            return WatchEvent.MISSING
        if self._was_missing:
            self._was_missing = False
            self._last = state
            return WatchEvent.CHANGED
        if self._expected is not None:
            self._expected = None
            if state == self._last:
                return WatchEvent.UNCHANGED
        if self._last is None:
            self._last = state
            return WatchEvent.UNCHANGED
        if state != self._last:
            self._last = state
            return WatchEvent.CHANGED
        return WatchEvent.UNCHANGED

    def note_write(self, mtime_ns: int, size: int) -> None:
        """Register the disk state produced by our own save (echo suppression)."""
        state = (mtime_ns, size)
        self._expected = state
        self._last = state

    def _stat(self):
        try:
            st = self.stat_fn(self.path)
        except FileNotFoundError:
            return None
        except OSError:
            return self._last
        return (st.st_mtime_ns, st.st_size)
```

```python
"""Line-level structural Markdown checks for MD Viewer (pure, Qt-free).

Errors (spec section 5.2): unclosed fenced code block; table data row whose
column count differs from the header; table row without a |---| separator
row. Warnings: heading missing the space after #; unbalanced ** or __
markers; odd number of inline backticks. Warnings ignore inline code spans
and fenced block content. No full CommonMark parsing is performed.
"""

import re
from dataclasses import dataclass

_FENCE_RE = re.compile(r"^ {0,3}(`{3,}|~{3,})(.*)$")
_HEADING_RE = re.compile(r"^ {0,3}(#{1,6})(?=[^\s#])")
_CODE_SPAN_RE = re.compile(r"`+[^`]+`+")


@dataclass(frozen=True)
class Issue:
    line: int      # 1-based
    start: int     # 0-based column, inclusive
    end: int       # 0-based column, exclusive
    severity: str  # "error" or "warning"
    message: str


def column_count(line: str) -> int:
    """Count pipe-separated cells in a Markdown table row."""
    s = line.strip()
    if s.startswith("|"):
        s = s[1:]
    if s.endswith("|"):
        s = s[:-1]
    return len(s.split("|"))


def _fence_info(line: str):
    """Return (fence_char, marker_length, rest) when the line is a fence line."""
    m = _FENCE_RE.match(line)
    if not m:
        return None
    return m.group(1)[0], len(m.group(1)), m.group(2)


def _is_table_separator(line: str) -> bool:
    """True for GFM separator rows such as `| --- | :---: |`."""
    s = line.strip()
    if not s or "|" not in s:
        return False
    body = s
    if body.startswith("|"):
        body = body[1:]
    if body.endswith("|"):
        body = body[:-1]
    for cell in body.split("|"):
        c = cell.strip()
        if not c or "-" not in c or not all(ch in "-:" for ch in c):
            return False
    return True


def _is_table_data_row(lines: list[str], i: int) -> bool:
    """True when lines[i] belongs to a table whose separator row is above it."""
    j = i - 1
    while j >= 0:
        if _is_table_separator(lines[j]):
            return True
        if "|" not in lines[j] or _fence_info(lines[j]) is not None:
            return False
        j -= 1
    return False


def _check_content(lines: list[str], i: int, issues: list[Issue]) -> None:
    line = lines[i]
    n = len(lines)

    if _is_table_separator(line):
        if i > 0 and "|" in lines[i - 1] and not _is_table_separator(lines[i - 1]):
            expected = column_count(lines[i - 1])
            j = i + 1
            while (j < n and "|" in lines[j]
                   and not _is_table_separator(lines[j])
                   and _fence_info(lines[j]) is None):
                got = column_count(lines[j])
                if got != expected:
                    issues.append(Issue(
                        j + 1, 0, len(lines[j]), "error",
                        f"Table column count differs from header "
                        f"(expected {expected}, got {got})",
                    ))
                j += 1
        return

    if ("|" in line and not _is_table_data_row(lines, i)
            and i + 1 < n and "|" in lines[i + 1]
            and not _is_table_separator(lines[i + 1])
            and _fence_info(lines[i + 1]) is None):
        issues.append(Issue(
            i + 2, 0, len(lines[i + 1]), "error",
            "Table row is missing a |---| separator row",
        ))

    m = _HEADING_RE.match(line)
    if m:
        indent = len(line) - len(line.lstrip(" "))
        issues.append(Issue(
            i + 1, indent, indent + len(m.group(1)), "warning",
            "Heading is missing a space after #",
        ))

    stripped = _CODE_SPAN_RE.sub("", line)
    if stripped.count("**") % 2 == 1:
        issues.append(Issue(i + 1, 0, len(line), "warning", "Unbalanced ** markers"))
    if stripped.count("__") % 2 == 1:
        issues.append(Issue(i + 1, 0, len(line), "warning", "Unbalanced __ markers"))
    if line.count("`") % 2 == 1:
        issues.append(Issue(i + 1, 0, len(line), "warning", "Odd number of inline backticks"))


def check(text: str) -> list[Issue]:
    """Scan a whole document; return issues sorted by (line, start)."""
    lines = text.split("\n")
    issues: list[Issue] = []
    fence = None       # (fence_char, marker_length) of the open fence
    fence_open = None  # (line_index, indent, marker_length) of the open fence

    for i, line in enumerate(lines):
        info = _fence_info(line)
        if fence is None:
            if info is not None:
                char, length, rest = info
                if not (char == "`" and "`" in rest):
                    fence = (char, length)
                    indent = len(line) - len(line.lstrip(" "))
                    fence_open = (i, indent, length)
            else:
                _check_content(lines, i, issues)
        elif (info is not None and info[0] == fence[0]
              and info[1] >= fence[1] and info[2].strip() == ""):
            fence = None
            fence_open = None

    if fence is not None:
        i, indent, length = fence_open
        issues.append(Issue(
            i + 1, indent, indent + length, "error",
            "Unclosed fenced code block",
        ))

    issues.sort(key=lambda issue: (issue.line, issue.start))
    return issues
```

"""Contextual Markdown completion and Enter continuation logic (Qt-free)."""

import re
from dataclasses import dataclass

from mdviewer.core.mdcheck import column_count

AUTOCLOSE_PAIRS = {"*": "*", "_": "_", "`": "`", "[": "]", "(": ")"}

FENCE_LANGUAGES = (
    "python", "bash", "powershell", "javascript", "typescript", "json",
    "yaml", "xml", "html", "css", "c", "cpp", "csharp", "go", "rust",
    "java", "sql", "toml", "text",
)

_FENCE_LINE_RE = re.compile(r"^\s*```")
_HEADING_RE = re.compile(r"^(\s*)(#+)")
_TASK_MARKER_RE = re.compile(r"^\s*[-*+]\s*$")
_QUOTE_RE = re.compile(r"^\s*((?:>[ \t]*)+)\S")
_QUOTE_BARE_RE = re.compile(r"^\s*((?:>[ \t]*)+)$")
_BULLET_RE = re.compile(r"^(\s*)([-*+])([ \t]+)(.*)$")
_BULLET_BARE_RE = re.compile(r"^(\s*)([-*+])$")
_ORDERED_RE = re.compile(r"^(\s*)(\d+)([.)])([ \t]+)(.*)$")
_ORDERED_BARE_RE = re.compile(r"^(\s*)(\d+)([.)])$")


@dataclass(frozen=True)
class Suggestion:
    text: str
    kind: str  # "token" completes in place; "line" inserts a new line below


def suggestions_for(line: str, col: int) -> list[Suggestion]:
    """Completion candidates for a line/cursor context.

    Priority: fence languages, heading, task list, quote, table.
    """
    if _FENCE_LINE_RE.match(line):
        return [Suggestion(lang, "token") for lang in FENCE_LANGUAGES]
    heading = _HEADING_RE.match(line)
    if heading is not None and col <= heading.end(2) + 1:
        return [Suggestion("#" * n + " ", "token") for n in range(1, 7)]
    if _TASK_MARKER_RE.match(line):
        return [Suggestion("- [ ] ", "token"), Suggestion("- [x] ", "token")]
    if line.lstrip().startswith(">"):
        return [Suggestion("> ", "token"), Suggestion("> - ", "token")]
    if "|" in line:
        count = column_count(line)
        return [
            Suggestion("| " + " | ".join(["---"] * count) + " |", "line"),
            Suggestion("| " + " | ".join([""] * count) + " |", "line"),
        ]
    return []


def should_continue_on_enter(line: str, col: int, in_fence: bool = False) -> str | None:
    """Decide Enter continuation on the editor page.

    None: plain Enter. "": clear the current marker and insert a blank
    line (empty list item or empty quote = exit). Non-empty: prefix to
    insert after the newline. No continuation inside fences or on lines
    containing |.
    """
    if in_fence or "|" in line:
        return None

    quote = _QUOTE_RE.match(line)
    if quote is not None and col >= quote.end(1):
        return quote.group(1).rstrip() + " "
    if _QUOTE_BARE_RE.match(line) is not None and col >= len(line):
        return ""

    bullet = _BULLET_RE.match(line)
    if bullet is not None and col >= len(bullet.group(1)) + 1:
        if bullet.group(4).strip():
            return f"{bullet.group(1)}{bullet.group(2)} "
        return ""
    if _BULLET_BARE_RE.match(line) is not None and col >= len(line):
        return ""

    ordered = _ORDERED_RE.match(line)
    if ordered is not None and col >= len(ordered.group(1)) + len(ordered.group(2)) + 1:
        if ordered.group(5).strip():
            return f"{ordered.group(1)}{int(ordered.group(2)) + 1}{ordered.group(3)} "
        return ""
    if _ORDERED_BARE_RE.match(line) is not None and col >= len(line):
        return ""

    return None
```

### Review Focus (Task 8)

Inputs the spec implies but does not spell out, most likely to bite first.
Each has a smoke check in Task 8:

- A CRLF file opened, edited and saved must stay CRLF (`QPlainTextEdit`
  silently normalizes to `\n`; "no line-ending conversion" means we restore
  the file's newline style on save).
- Closing the window (Alt+F4, title-bar X, File > Exit) with unsaved changes
  must ask `Save changes to <name>?`; Cancel keeps the window open.
- Saving text the remembered encoding cannot represent (e.g. CJK in a
  Windows-1252 file) must leave the file on disk untouched and the buffer
  dirty, and offer to save as UTF-8 instead.
- A non-breaking space (U+00A0) in the file must survive a save
  (`QPlainTextEdit.toPlainText()` turns it into a normal space).
- Saved window geometry pointing at a monitor that is no longer connected
  must not restore the window off-screen.

"""Application bootstrap: QApplication, settings load/save, window lifecycle."""

import sys

from PySide6.QtWidgets import QApplication

from mdviewer.core import settings
from mdviewer.main_window import APP_NAME, MainWindow


def build(argv: list[str]) -> tuple[QApplication, MainWindow]:
    """Create (or reuse) the QApplication and a MainWindow from saved settings."""
    app = QApplication.instance() or QApplication([sys.argv[0], *argv])
    app.setStyle("windowsvista")
    app.setApplicationName(APP_NAME)
    return app, MainWindow(settings.load())


def save_settings(window: MainWindow) -> None:
    """Persist theme, geometry and zoom; a failed write must not crash on exit."""
    try:
        settings.save(None, window.settings_snapshot())
    except OSError:
        pass


def main(argv: list[str]) -> int:
    app, window = build(argv)
    window.show()  # shown first so an open-error box has a visible parent
    if argv:
        window.open_file(argv[0])
    code = app.exec()
    save_settings(window)
    return code
```

def ask(box: QMessageBox) -> QMessageBox.StandardButton:
    """Run a modal message box; return the standard button the user chose."""
    box.exec()
    return box.standardButton(box.clickedButton())


def show_error(parent, text: str) -> None:
    QMessageBox.critical(parent, APP_NAME, text)


def pick_open_path(parent) -> str:
    path, _ = QFileDialog.getOpenFileName(parent, "Open", "", OPEN_FILTER)
    return path


def pick_save_path(parent, start: str) -> str:
    path, _ = QFileDialog.getSaveFileName(parent, "Save As", start, SAVE_FILTER)
    return path


def _fmt_size(n: int) -> str:
    if n < 1024:
        return f"{n} B"
    if n < 1024 * 1024:
        return f"{n / 1024:.1f} KB"
    return f"{n / (1024 * 1024):.1f} MB"


def _open_error_text(path: Path, exc: OSError) -> str:
    """Notepad-style wording for a failed open."""
    if isinstance(exc, FileNotFoundError):
        return f"{path}\nFile not found.\nCheck the file name and try again."
    if isinstance(exc, PermissionError):
        return f"{path}\nAccess is denied."
    return f"{path}\n{exc.strerror or exc}"


def _local_paths(mime) -> list[str]:
    return [url.toLocalFile() for url in mime.urls() if url.isLocalFile()]

    PREVIEW = "preview"
    EDIT = "edit"

    # --- Buffer ------------------------------------------------------------

    @property
    def buffer(self) -> str:
        """Editor text with \\n breaks. toPlainText() would turn NBSP into spaces."""
        return self.editor.document().toRawText().replace("\u2029", "\n")

    def _load(self, path: Path | None, raw: bytes) -> None:
        """Decode raw file bytes into the buffer; remember encoding and newline style."""
        text, self.encoding = encoding.detect(raw)
        self.newline = "\r\n" if "\r\n" in text else "\n"

        self._size = len(raw)
        self.editor.setPlainText(text.replace("\r\n", "\n"))

            return

        if not self._ok_to_replace():
            return

        if self.loaded_path is None:
            return self.on_save_as()
        return self._save_to(self.loaded_path)

    def on_save_as(self) -> bool:
        start = str(self.loaded_path) if self.loaded_path else "Untitled.md"
        path = pick_save_path(self, start)
        if not path:
            return False
        target = Path(path)
        if not target.suffix:
            target = target.with_suffix(".md")
        return self._save_to(target)

    def on_close(self) -> None:
        if not self._ok_to_replace():
            return
        self._load(None, b"")
        self._show_mode(self.PREVIEW)

    def _save_to(self, path: Path) -> bool:
        """Write the buffer with the file's own newline style and encoding."""
        text = self.buffer.replace("\n", self.newline)
        try:
            raw = encoding.encode(text, self.encoding)
        except UnicodeEncodeError:
            if not self._offer_utf8(path):
                return False
            self.encoding = "utf-8"
            raw = encoding.encode(text, self.encoding)
        try:
            path.write_bytes(raw)
        except OSError as exc:
            show_error(self, f"{path}\n{exc.strerror or exc}")
            return False
        self.loaded_path = path
        self._size = len(raw)
        self.editor.setModified(False)
        self.dirty = False
        self._update_chrome()
        return True

    def _offer_utf8(self, path: Path) -> bool:
        label = ENCODING_LABELS.get(self.encoding, self.encoding)
        box = QMessageBox(
            QMessageBox.Icon.Warning,
            APP_NAME,
            f"{path.name} contains characters that cannot be saved in {label}.\n"
            "Save it as UTF-8 instead?",
            QMessageBox.StandardButton.Yes | QMessageBox.StandardButton.Cancel,
            self,
        )
        box.setDefaultButton(QMessageBox.StandardButton.Yes)
        return ask(box) == QMessageBox.StandardButton.Yes

    def _prompt_save(self) -> str:
        """Ask 'Save changes to <name>?'. Returns 'save' (saved OK), 'discard' or 'cancel'."""
        name = self.loaded_path.name if self.loaded_path else "Untitled"
        buttons = QMessageBox.StandardButton
        box = QMessageBox(
            QMessageBox.Icon.Warning,
            APP_NAME,
            f"Save changes to {name}?",
            buttons.Save | buttons.Discard | buttons.Cancel,
            self,
        )
        box.setDefaultButton(buttons.Save)
        box.button(buttons.Discard).setText("Don't Save")
        answer = ask(box)
        if answer == buttons.Save:
            return "save" if self.on_save() else "cancel"
        if answer == buttons.Discard:
            return "discard"
        return "cancel"

    def _ok_to_replace(self) -> bool:
        """True when the buffer may be replaced: it is clean, was saved, or was discarded."""
        return not self.dirty or self._prompt_save() != "cancel"

    def _reload_or_clear(self) -> None:
        """Don't Save: put the disk content back (empty for Untitled or unreadable files)."""
        if self.loaded_path is not None:
            try:
                raw = self.loaded_path.read_bytes()
            except OSError:
                raw = None
            if raw is not None:
                self._load(self.loaded_path, raw)
                return
        self.editor.setPlainText("")
        self.editor.setModified(False)
        self.dirty = False

    def set_mode(self, mode: str) -> None:

            self._update_chrome()
            return
        if mode == self.PREVIEW and self.dirty:
            answer = self._prompt_save()
            if answer == "cancel":
                self._update_chrome()  # the action group already moved the radio check
                return
            if answer == "discard":

            self, f"About {APP_NAME}", f"{APP_NAME} 0.1.0\n\nA Notepad-like Markdown viewer for Windows."
        )

    # --- Chrome: title, status bar, action state ---------------------------

    def _update_chrome(self) -> None:
        editing = self.mode == self.EDIT
        (self.act_edit if editing else self.act_preview).setChecked(True)
        for act in self._edit_only_actions:
            act.setEnabled(editing)

    def _open_dropped(self, paths: list[str]) -> None:
        if paths and self._ok_to_replace():
            self.open_file(paths[0])

    def _defer_drop(self, event) -> None:
        # Defer so a save prompt does not block Explorer's drag-and-drop loop.
        paths = _local_paths(event.mimeData())
        event.acceptProposedAction()
        QTimer.singleShot(0, lambda: self._open_dropped(paths))

    def dragEnterEvent(self, event) -> None:
        if event.mimeData().hasUrls():
            event.acceptProposedAction()

    def dropEvent(self, event) -> None:
        self._defer_drop(event)

    def eventFilter(self, obj, event) -> bool:
        """Open files dropped on the editor instead of inserting their path as text."""
        if event.type() in _DROP_EVENTS and event.mimeData().hasUrls():
            if event.type() == QEvent.Type.Drop:
                self._defer_drop(event)
            else:
                event.acceptProposedAction()
            return True
        return super().eventFilter(obj, event)

    # --- Window lifecycle and settings -------------------------------------

    def closeEvent(self, event) -> None:
        if self._ok_to_replace():
            event.accept()
        else:
            event.ignore()

    def _restore_geometry(self, rect: dict | None) -> None:
        if not rect:
            self.resize(*DEFAULT_SIZE)
            return
        geo = QRect(rect["x"], rect["y"], rect["width"], rect["height"])
        self.resize(geo.size())
        # Skip the position if it lies on a monitor that is no longer connected.
        if any(screen.availableGeometry().intersects(geo) for screen in QGuiApplication.screens()):
            self.move(geo.topLeft())

    def settings_snapshot(self) -> dict:
        """Same shape as settings.load(); pos()/size() pair with move()/resize()."""
        pos, size = self.pos(), self.size()
        return {
            "theme": self._theme_choice,
            "window": {"x": pos.x(), "y": pos.y(), "width": size.width(), "height": size.height()},
            "preview_zoom": self._zoom,
        }

class _Renderer(mistune.HTMLRenderer):
    """HTML renderer with Pygments code blocks and base-dir URL resolution."""

    def __init__(self, base_dir: Path | None):
        super().__init__(escape=False, allow_harmful_protocols=_ALLOWED_PROTOCOLS)
        self._base_dir = base_dir

    def block_code(self, code: str, info: str | None = None) -> str:
        lang = info.split(None, 1)[0] if info and info.strip() else ""
        if lang:
            try:
                lexer = get_lexer_by_name(lang)
            except ClassNotFound:
                lexer = None
            if lexer is not None:
                return highlight(code, lexer, HtmlFormatter(cssclass="highlight"))
        return super().block_code(code, info)

    def link(self, text: str, url: str, title: str | None = None) -> str:
        return super().link(text, self._resolve(url), title)

    def image(self, text: str, url: str, title: str | None = None) -> str:
        return super().image(text, self._resolve(url), title)

    def _resolve(self, url: str) -> str:
        """Turn a document-relative URL into an absolute file: URI."""
        if self._base_dir is None or not url or url.startswith(("#", "/", "\\")):
            return url
        parts = urlsplit(url)
        if len(parts.scheme) == 1:  # C:/pics/a.png - a Windows drive path
            return Path(unquote(url)).as_uri()
        if parts.scheme or parts.netloc:  # http:, mailto:, file:, ...
            return url
        target = Path(os.path.normpath(Path(self._base_dir).absolute() / unquote(parts.path)))
        uri = target.as_uri()
        if parts.query:
            uri += "?" + parts.query
        if parts.fragment:
            uri += "#" + parts.fragment
        return uri

    pygments_css = HtmlFormatter(style=_PYGMENTS_STYLES[theme]).get_style_defs(".highlight")
    return f":root {{ {variables}}}\n{_SHARED_CSS}\n{pygments_css}\n"


def render_body(text: str, base_dir: Path | None = None) -> str:
    markdown = mistune.create_markdown(renderer=_Renderer(base_dir), plugins=PLUGINS)

def build_page(text: str, theme: str, base_dir: Path | None = None) -> tuple[str, bool]:
    """Full HTML page; falls back to the escaped raw text if rendering fails."""
    try:

    except Exception:  # any renderer/lexer bug must not blank the preview

        '<!DOCTYPE html>\n<html><head><meta charset="utf-8">'
        f"<style>{page_css(theme)}</style></head>"
        f'<body><article class="markdown-body">{body}</article></body></html>\n'
    ), ok

"""Preview page: a QWebEngineView showing Markdown rendered by core/render.py."""

import tempfile
from pathlib import Path

from PySide6.QtCore import QUrl
from PySide6.QtGui import QColor, QDesktopServices
from PySide6.QtWebEngineCore import QWebEnginePage, QWebEngineScript, QWebEngineSettings
from PySide6.QtWebEngineWidgets import QWebEngineView

from mdviewer.core import render


def open_external(url: QUrl) -> None:
    """Hand a clicked link to Windows (browser, mail client, default app)."""
    QDesktopServices.openUrl(url)


class _Page(QWebEnginePage):
    """Keeps the preview on the document: clicked links open outside the app."""

    def __init__(self, document_url: QUrl, parent=None):
        super().__init__(parent)
        self.document_url = document_url

    def acceptNavigationRequest(self, url, nav_type, is_main_frame) -> bool:
        if nav_type != QWebEnginePage.NavigationType.NavigationTypeLinkClicked:
            return True  # our own loads
        no_fragment = QUrl.UrlFormattingOption.RemoveFragment
        if url.adjusted(no_fragment) == self.document_url.adjusted(no_fragment):
            return True  # in-page anchor: footnotes, table-of-contents links
        open_external(url)
        return False


class MarkdownPreview(QWebEngineView):
    """Loads each render from a temp file: no 2 MB setHtml limit, anchors keep working."""

    def __init__(self, parent=None):
        super().__init__(parent)
        self._tmpdir = tempfile.TemporaryDirectory(prefix="mdviewer-", ignore_cleanup_errors=True)
        self.page_file = Path(self._tmpdir.name) / "preview.html"
        self.setPage(_Page(QUrl.fromLocalFile(str(self.page_file)), self))
        # Raw HTML is allowed in Markdown; scripts in it must never run.
        self.settings().setAttribute(QWebEngineSettings.WebAttribute.JavascriptEnabled, False)
        self.last_html = ""
        self._scroll = None
        self.loadFinished.connect(self._restore_scroll)

    def show_markdown(
        self, text: str, theme: str, base_dir: Path | None = None, keep_scroll: bool = False
    ) -> bool:
        """Render and load; returns False when the <pre> fallback was used."""
        page_html, ok = render.build_page(text, theme, base_dir)
        self._scroll = self.page().scrollPosition() if keep_scroll else None
        self.page().setBackgroundColor(QColor(render.PAGE_BACKGROUND[theme]))
        self.last_html = page_html
        self.page_file.write_text(page_html, encoding="utf-8")
        self.load(QUrl.fromLocalFile(str(self.page_file)))
        return ok

    def _restore_scroll(self, _ok: bool) -> None:
        if self._scroll is None:
            return
        x, y = self._scroll.x(), self._scroll.y()
        self._scroll = None
        # ApplicationWorld scripts still run with page JavaScript disabled.
        self.page().runJavaScript(
            f"window.scrollTo({x}, {y});", QWebEngineScript.ScriptWorldId.ApplicationWorld.value
        )

def autoclose_action(line: str, col: int, ch: str) -> str | None:
    """'over' to step over the closer at the cursor, 'pair' to insert ch + partner, None to type normally."""
    before = line[col - 1] if col > 0 else ""
    after = line[col] if col < len(line) else ""
    if ch in _CLOSERS and after == ch:
        return "over"
    if ch not in AUTOCLOSE_PAIRS:
        return None
    if after and not after.isspace() and after not in _AFTER_PAIR_OK:
        return None  # never pair directly before a word
    if ch in _SYMMETRIC:
        if before and not before.isspace() and before not in _BEFORE_MARKER_OK:
            return None  # inside a word (my_var) or after another marker (```)
        if ch == "*" and not line[:col].strip():
            return None  # a bullet marker at line start
    return "pair"


def deletes_pair(line: str, col: int) -> bool:
    """Backspace between an empty auto-closed pair removes both characters."""
    return 0 < col < len(line) and AUTOCLOSE_PAIRS.get(line[col - 1]) == line[col]


def token_prefix(line: str, col: int) -> str:
    """Text the completion popup filters on: the partial fence language, else ''."""
    fence = _FENCE_PREFIX_RE.match(line)
    if fence is not None and col >= fence.end(1):
        return line[fence.end(1):col].strip()
    return ""


def apply_suggestion(line: str, col: int, suggestion: Suggestion) -> tuple[str, int]:
    """Return (replacement for the whole line, cursor offset within it)."""
    text = suggestion.text
    if suggestion.kind == "line":
        new = f"{line}\n{text}"
        return new, len(new)
    if text.startswith("#"):
        m = _HEADING_TOKEN_RE.match(line)
        if m is not None:
            head = m.group(1) + text
            return head + line[m.end():], len(head)
    elif text.startswith("- ["):
        new = _INDENT_RE.match(line).group(0) + text
        return new, len(new)
    elif text.startswith(">"):
        m = _QUOTE_TOKEN_RE.match(line)
        if m is not None:
            head = m.group(1) + text
            return head + line[m.end():], len(head)
    else:
        m = _FENCE_PREFIX_RE.match(line)
        if m is not None:
            new = m.group(1) + text
            return new, len(new)
    return line[:col] + text + line[col:], col + len(text)

"""Editor page: QPlainTextEdit with Markdown highlighting, underlines, and completion."""

import re

from PySide6.QtCore import QEvent, QStringListModel, Qt, QTimer
from PySide6.QtGui import QColor, QFont, QSyntaxHighlighter, QTextCharFormat, QTextCursor
from PySide6.QtWidgets import QCompleter, QPlainTextEdit, QToolTip

from mdviewer.core import mdcheck
from mdviewer.core.completion import (
    AUTOCLOSE_PAIRS,
    apply_suggestion,
    autoclose_action,
    deletes_pair,
    should_continue_on_enter,
    suggestions_for,
    token_prefix,
)

TRIGGER_CHARS = "#|`>-*_["
REFRESH_MS = 250

COLORS = {
    "light": {
        "heading": "#0550ae", "code": "#953800", "link": "#0969da", "marker": "#cf222e",
        "quote": "#59636e", "table": "#8250df", "fence": "#116329", "comment": "#6e7781",
        "error": "#d1242f", "warning": "#e36209",
    },
    "dark": {
        "heading": "#79c0ff", "code": "#ffa657", "link": "#58a6ff", "marker": "#ff7b72",
        "quote": "#9198a1", "table": "#d2a8ff", "fence": "#7ee787", "comment": "#8b949e",
        "error": "#f85149", "warning": "#f0883e",
    },
}

# Block states: 0 normal, 1 inside an HTML comment, >= 1000 inside a fence
# (1000 + length for backtick fences, 2000 + length for tilde fences).
NORMAL, COMMENT, FENCE_BACKTICK, FENCE_TILDE = 0, 1, 1000, 2000

_FENCE_RE = re.compile(r"^ {0,3}(`{3,}|~{3,})(.*)$")
_HEADING_RE = re.compile(r"^ {0,3}#{1,6}(?:\s|$)")
_QUOTE_RE = re.compile(r"^\s*>")
_LIST_RE = re.compile(r"^(\s*)([-*+]|\d+[.)])(?=\s|$)")
_BOLD_RE = re.compile(r"(\*\*|__)(?=\S)(.+?)(?<=\S)\1")
_ITALIC_RE = re.compile(r"(?<![*_\w])([*_])(?=[^\s*_])(.+?)(?<=[^\s*_])\1(?![*_\w])")
_LINK_RE = re.compile(r"!?\[[^\]\n]*\]\([^)\n]*\)|<https?://[^>\s]+>|https?://\S+")
_CODE_RE = re.compile(r"(`+)(.+?)\1")
_COMMENT_RE = re.compile(r"<!--.*?-->")
_FENCE_LINE_RE = re.compile(r"^\s*```")
_POPUP_KEYS = (
    Qt.Key.Key_Return, Qt.Key.Key_Enter, Qt.Key.Key_Escape, Qt.Key.Key_Tab, Qt.Key.Key_Backtab,
)
_COMMAND_MODS = (
    Qt.KeyboardModifier.ControlModifier | Qt.KeyboardModifier.AltModifier | Qt.KeyboardModifier.MetaModifier
)


def _fence_state(text: str) -> int | None:
    """Block state for a line that opens a fence, else None (mirrors mdcheck)."""
    m = _FENCE_RE.match(text)
    if m is None:
        return None
    marker, rest = m.group(1), m.group(2)
    if marker[0] == "`":
        return None if "`" in rest else FENCE_BACKTICK + min(len(marker), 999)
    return FENCE_TILDE + min(len(marker), 999)


def _closes_fence(text: str, state: int) -> bool:
    m = _FENCE_RE.match(text)
    if m is None or m.group(2).strip():
        return False
    char = "`" if state < FENCE_TILDE else "~"
    return m.group(1)[0] == char and len(m.group(1)) >= state % 1000


def _is_table_separator(text: str) -> bool:
    s = text.strip()
    return "|" in s and "-" in s and set(s) <= set("|-: \t")


def _char_format(color=None, bold=False, italic=False, underline=False) -> QTextCharFormat:
    fmt = QTextCharFormat()
    if color:
        fmt.setForeground(QColor(color))
    if bold:
        fmt.setFontWeight(QFont.Weight.Bold)
    if italic:
        fmt.setFontItalic(True)
    if underline:
        fmt.setFontUnderline(True)
    return fmt


class MarkdownHighlighter(QSyntaxHighlighter):
    """Structural colors per block, plus mdcheck wavy underlines refreshed after edits."""

    def __init__(self, document):
        super().__init__(document)
        self._issues: dict[int, list[mdcheck.Issue]] = {}
        self._refreshing = False
        self._timer = QTimer(self)
        self._timer.setSingleShot(True)
        self._timer.setInterval(REFRESH_MS)
        self._timer.timeout.connect(self.refresh_issues)
        document.contentsChange.connect(self._schedule_refresh)
        self._build_formats("light")

    # --- public API --------------------------------------------------------

    def set_theme(self, theme: str) -> None:
        self._build_formats(theme)
        self._refreshing = True
        try:
            self.rehighlight()
        finally:
            self._refreshing = False

    def refresh_issues(self) -> None:
        """Re-run mdcheck; re-highlight only the lines whose issues changed."""
        issues: dict[int, list[mdcheck.Issue]] = {}
        for issue in mdcheck.check(self.document().toPlainText()):
            issues.setdefault(issue.line, []).append(issue)
        changed = [
            line for line in set(issues) | set(self._issues)
            if issues.get(line) != self._issues.get(line)
        ]
        self._issues = issues
        self._refreshing = True
        try:
            for line in changed:
                block = self.document().findBlockByNumber(line - 1)
                if block.isValid():
                    self.rehighlightBlock(block)
        finally:
            self._refreshing = False

    def starts_in_fence(self, block) -> bool:
        """True when the block is fenced-code content (or the closing fence)."""
        previous = block.previous()
        return previous.isValid() and previous.userState() >= FENCE_BACKTICK

    def message_at(self, line: int, col: int) -> str:
        return "\n".join(
            issue.message for issue in self._issues.get(line, [])
            if issue.start <= col < max(issue.end, issue.start + 1)
        )

    # --- QSyntaxHighlighter --------------------------------------------------

    def highlightBlock(self, text: str) -> None:
        state = max(self.previousBlockState(), NORMAL)
        if state >= FENCE_BACKTICK:
            self.setFormat(0, len(text), self._formats["fence"])
            if _closes_fence(text, state):
                state = NORMAL
        else:
            state = self._highlight_markdown(text, state)
        self.setCurrentBlockState(state)
        self._apply_issues(text)

    # --- internals -----------------------------------------------------------

    def _schedule_refresh(self, *_args) -> None:
        if not self._refreshing:  # our own re-highlighting also emits contentsChange
            self._timer.start()

    def _build_formats(self, theme: str) -> None:
        c = COLORS[theme]
        self._formats = {
            "heading": _char_format(c["heading"], bold=True),
            "bold": _char_format(bold=True),
            "italic": _char_format(italic=True),
            "code": _char_format(c["code"]),
            "link": _char_format(c["link"], underline=True),
            "marker": _char_format(c["marker"], bold=True),
            "quote": _char_format(c["quote"], italic=True),
            "table": _char_format(c["table"]),
            "fence": _char_format(c["fence"]),
            "comment": _char_format(c["comment"], italic=True),
        }
        self._underlines = {}
        for severity in ("error", "warning"):
            fmt = QTextCharFormat()
            fmt.setUnderlineStyle(QTextCharFormat.UnderlineStyle.WaveUnderline)
            fmt.setUnderlineColor(QColor(c[severity]))
            self._underlines[severity] = fmt

    def _merge(self, start: int, length: int, fmt: QTextCharFormat) -> None:
        for pos in range(start, start + length):
            merged = self.format(pos)
            merged.merge(fmt)
            self.setFormat(pos, 1, merged)

    def _highlight_markdown(self, text: str, state: int) -> int:
        f = self._formats
        start = 0
        if state == COMMENT:
            end = text.find("-->")
            if end < 0:
                self.setFormat(0, len(text), f["comment"])
                return COMMENT
            start = end + 3
        else:
            fence = _fence_state(text)
            if fence is not None:
                self.setFormat(0, len(text), f["fence"])
                return fence
            self._line_rules(text)
        for m in _BOLD_RE.finditer(text, start):
            self._merge(m.start(), m.end() - m.start(), f["bold"])
        for m in _ITALIC_RE.finditer(text, start):
            self._merge(m.start(), m.end() - m.start(), f["italic"])
        for regex, key in ((_LINK_RE, "link"), (_CODE_RE, "code"), (_COMMENT_RE, "comment")):
            for m in regex.finditer(text, start):
                self.setFormat(m.start(), m.end() - m.start(), f[key])
        if start:
            self.setFormat(0, start, f["comment"])
        opening = text.rfind("<!--")
        if opening >= start and text.find("-->", opening + 4) < 0:
            self.setFormat(opening, len(text) - opening, f["comment"])
            return COMMENT
        return NORMAL

    def _line_rules(self, text: str) -> None:
        f = self._formats
        if _HEADING_RE.match(text):
            self.setFormat(0, len(text), f["heading"])
        elif _QUOTE_RE.match(text):
            self.setFormat(0, len(text), f["quote"])
        elif _is_table_separator(text):
            self.setFormat(0, len(text), f["table"])
        marker = _LIST_RE.match(text)
        if marker is not None:
            self.setFormat(marker.start(2), len(marker.group(2)), f["marker"])

    def _apply_issues(self, text: str) -> None:
        line = self.currentBlock().blockNumber() + 1
        # Warnings first so an error on the same characters wins.
        for issue in sorted(self._issues.get(line, []), key=lambda i: i.severity == "error"):
            start, end = min(issue.start, len(text)), min(issue.end, len(text))
            self._merge(start, end - start, self._underlines[issue.severity])


class MarkdownEditor(QPlainTextEdit):
    """Notepad-style editor plus auto-close pairs, Enter continuation, and a completer."""

    def __init__(self, parent=None):
        super().__init__(parent)
        self.highlighter = MarkdownHighlighter(self.document())
        self._model = QStringListModel(self)
        self.completer = QCompleter(self._model, self)
        self.completer.setWidget(self)
        self.completer.setCompletionMode(QCompleter.CompletionMode.PopupCompletion)
        self.completer.setCaseSensitivity(Qt.CaseSensitivity.CaseInsensitive)
        self.completer.activated[str].connect(self._insert_completion)
        self._suggestions = {}

    def set_theme(self, theme: str) -> None:
        self.highlighter.set_theme(theme)

    # --- keys ----------------------------------------------------------------

    def keyPressEvent(self, event) -> None:
        key, mods = event.key(), event.modifiers()
        if self.completer.popup().isVisible() and key in _POPUP_KEYS:
            event.ignore()  # the completer accepts or dismisses
            return
        if key == Qt.Key.Key_Space and mods == Qt.KeyboardModifier.ControlModifier:
            self._show_completions()
            return
        if key in (Qt.Key.Key_Return, Qt.Key.Key_Enter) and not (mods & _COMMAND_MODS):
            if not self._continue_on_enter():
                cursor = self.textCursor()
                cursor.insertText("\n")  # never Shift+Enter's U+2028 soft break
                self.setTextCursor(cursor)
            self.ensureCursorVisible()
            return
        if key == Qt.Key.Key_Backspace and not mods and self._delete_pair():
            self._after_typing("\b")
            return
        typed = event.text()
        # No modifier test here: AltGr ([ on many layouts) reports Ctrl+Alt.
        if not (len(typed) == 1 and typed.isprintable() and self._auto_close(typed)):
            super().keyPressEvent(event)
        self._after_typing(typed)

    def _auto_close(self, ch: str) -> bool:
        cursor = self.textCursor()
        if cursor.hasSelection() or self.highlighter.starts_in_fence(cursor.block()):
            return False
        action = autoclose_action(cursor.block().text(), cursor.positionInBlock(), ch)
        if action == "over":
            cursor.movePosition(QTextCursor.MoveOperation.Right)
        elif action == "pair":
            cursor.insertText(ch + AUTOCLOSE_PAIRS[ch])
            cursor.movePosition(QTextCursor.MoveOperation.Left)
        else:
            return False
        self.setTextCursor(cursor)
        return True

    def _delete_pair(self) -> bool:
        cursor = self.textCursor()
        if cursor.hasSelection() or not deletes_pair(cursor.block().text(), cursor.positionInBlock()):
            return False
        cursor.movePosition(QTextCursor.MoveOperation.Left)
        cursor.movePosition(QTextCursor.MoveOperation.Right, QTextCursor.MoveMode.KeepAnchor, 2)
        cursor.removeSelectedText()
        return True

    def _continue_on_enter(self) -> bool:
        cursor = self.textCursor()
        if cursor.hasSelection():
            return False
        block = cursor.block()
        prefix = should_continue_on_enter(
            block.text(), cursor.positionInBlock(), self.highlighter.starts_in_fence(block)
        )
        if prefix is None:
            return False
        cursor.beginEditBlock()  # one undo step
        if prefix == "":
            cursor.movePosition(QTextCursor.MoveOperation.StartOfBlock)
            cursor.movePosition(QTextCursor.MoveOperation.EndOfBlock, QTextCursor.MoveMode.KeepAnchor)
            cursor.insertText("\n")
        else:
            cursor.insertText("\n" + prefix)
        cursor.endEditBlock()
        self.setTextCursor(cursor)
        return True

    # --- completion ----------------------------------------------------------

    def _after_typing(self, typed: str) -> None:
        popup = self.completer.popup()
        if typed and typed in TRIGGER_CHARS:
            self._show_completions()
        elif popup.isVisible() and typed != " " and _FENCE_LINE_RE.match(self.textCursor().block().text()):
            self._show_completions()  # narrow fence languages as the user types
        else:
            popup.hide()  # a space or ordinary text ends the token

    def _show_completions(self) -> None:
        popup = self.completer.popup()
        cursor = self.textCursor()
        block = cursor.block()
        suggestions = [] if self.highlighter.starts_in_fence(block) else suggestions_for(
            block.text(), cursor.positionInBlock()
        )
        if not suggestions:
            popup.hide()
            return
        self._suggestions = {s.text: s for s in suggestions}
        self._model.setStringList(list(self._suggestions))
        self.completer.setCompletionPrefix(token_prefix(block.text(), cursor.positionInBlock()))
        if self.completer.completionCount() == 0:
            popup.hide()
            return
        popup.setCurrentIndex(self.completer.completionModel().index(0, 0))
        rect = self.cursorRect()
        rect.setWidth(popup.sizeHintForColumn(0) + popup.verticalScrollBar().sizeHint().width())
        self.completer.complete(rect)

    def _insert_completion(self, text: str) -> None:
        suggestion = self._suggestions.get(text)
        if suggestion is None:
            return
        cursor = self.textCursor()
        block = cursor.block()
        new_line, offset = apply_suggestion(block.text(), cursor.positionInBlock(), suggestion)
        start = block.position()
        cursor.beginEditBlock()
        cursor.movePosition(QTextCursor.MoveOperation.StartOfBlock)
        cursor.movePosition(QTextCursor.MoveOperation.EndOfBlock, QTextCursor.MoveMode.KeepAnchor)
        cursor.insertText(new_line)
        cursor.endEditBlock()
        cursor.setPosition(start + offset)
        self.setTextCursor(cursor)
        self.completer.popup().hide()

    # --- tooltips for underlined issues ---------------------------------------

    def viewportEvent(self, event) -> bool:
        if event.type() == QEvent.Type.ToolTip:
            cursor = self.cursorForPosition(event.pos())
            message = self.highlighter.message_at(cursor.blockNumber() + 1, cursor.positionInBlock())
            if message:
                QToolTip.showText(event.globalPos(), message, self)
            else:
                QToolTip.hideText()
            return True
        return super().viewportEvent(event)

  - `_watcher: Watcher | None`, `_watch_timer: QTimer` (1000 ms, always running).
  - `_watch(path: Path | None) -> None` - new watcher, baselined immediately; `None` for Untitled.
  - `_note_own_write(path: Path) -> None` - fresh watcher + `note_write` after our own save (fresh, so a "missing" state from before the save cannot echo).

  - `_read_disk() -> bytes | None` - read `loaded_path`; `None` on `OSError`.
  - `_reload_preview(warn: bool) -> None`, `_ask_reload() -> None`.

Design notes:
- `_poll_disk` does nothing while a `File changed on disk` dialog is open (`_busy`) or while any Qt modal is active. The change is not lost: the watcher's state only advances when `poll()` runs.
- A preview re-read failure leaves `_pending_reload` set, and each later tick retries silently. The watcher has already consumed that change event, so without the retry the preview could stay stale forever.
- **Keep my version** marks the buffer modified, because it now differs from disk. The spec's "no change" refers to the content, which stays untouched.

```python
    # --- File watching -------------------------------------------------------

    def _watch(self, path: Path | None) -> None:
        self._pending_reload = False
        self._watcher = Watcher(path, os.stat) if path is not None else None
        if self._watcher is not None:
            self._watcher.poll()  # baseline: the content we just loaded

    def _note_own_write(self, path: Path) -> None:
        """Expect the disk state our save produced so the next poll stays quiet."""
        self._pending_reload = False
        self._watcher = Watcher(path, os.stat)  # fresh: no stale "missing" state
        try:
            st = os.stat(path)
        except OSError:
            return  # first poll will baseline instead
        self._watcher.note_write(st.st_mtime_ns, st.st_size)

    def _read_disk(self) -> bytes | None:
        try:
            return self.loaded_path.read_bytes()
        except OSError:
            return None

    def _poll_disk(self) -> None:
        if self._watcher is None or self._busy or QApplication.activeModalWidget() is not None:
            return  # unpolled changes are picked up on a later tick
        event = self._watcher.poll()
        if event == WatchEvent.MISSING:
            self._warn(f'"{self.loaded_path.name}" was not found on disk.')
        elif event == WatchEvent.CHANGED:
            if self.mode == self.EDIT:
                self._busy = True
                try:
                    self._ask_reload()
                finally:
                    self._busy = False
            else:
                self._reload_preview(warn=True)
        elif self._pending_reload and self.mode == self.PREVIEW:
            self._reload_preview(warn=False)

    def _reload_preview(self, warn: bool) -> None:
        raw = self._read_disk()
        if raw is None:
            self._pending_reload = True
            if warn:
                self._warn(f'Could not read "{self.loaded_path.name}"; showing the last version.')
            return
        self._load(self.loaded_path, raw)
        self._render_preview(keep_scroll=True)
        self._update_chrome()

    def _ask_reload(self) -> None:
        name = self.loaded_path.name
        try:
            stamp = datetime.fromtimestamp(os.stat(self.loaded_path).st_mtime)
        except OSError:
            stamp = datetime.now()
        buttons = QMessageBox.StandardButton
        box = QMessageBox(
            QMessageBox.Icon.Warning,
            "File changed on disk",
            f'"{name}" was modified externally at {stamp:%H:%M:%S}. '
            "Reload it now? Your unsaved changes will be lost.",
            buttons.Yes | buttons.No,
            self,
        )
        box.button(buttons.Yes).setText("Reload")
        box.button(buttons.No).setText("Keep my version")
        box.setDefaultButton(buttons.Yes)
        if ask(box) != buttons.Yes:
            self.editor.document().setModified(True)  # buffer now differs from disk
            return
        raw = self._read_disk()
        if raw is None:
            self._warn(f'Could not read "{name}"; your version is kept.')
            return
        position = self.editor.textCursor().position()
        self._load(self.loaded_path, raw)
        cursor = self.editor.textCursor()
        cursor.setPosition(min(position, len(self.buffer)))
        self.editor.setTextCursor(cursor)
        self._update_chrome()
```

Note: `_ask_reload` builds the box with Yes/No relabelled **Reload** / **Keep my version**. No has `NoRole`, so Escape or closing the box means Keep, which is the safe choice.

```python
"""Find/Replace bar under the editor: plain-text search via QTextDocument.find.

QTextDocument positions count UTF-16 units, so all matching stays in Qt;
Python string offsets would drift after any emoji.
"""

from PySide6.QtCore import QEvent, Qt, QTimer
from PySide6.QtGui import QTextCursor, QTextDocument
from PySide6.QtWidgets import (
    QCheckBox,
    QHBoxLayout,
    QLabel,
    QLineEdit,
    QPushButton,
    QToolButton,
    QVBoxLayout,
    QWidget,
)

RECOUNT_MS = 200


class FindBar(QWidget):
    def __init__(self, editor, parent=None):
        super().__init__(parent)
        self.editor = editor

        self.find_edit = QLineEdit()
        self.find_edit.setPlaceholderText("Find")
        self.case_box = QCheckBox("Match case")
        self.count_label = QLabel()
        self.count_label.setMinimumWidth(90)
        self.prev_button = QPushButton("Previous")
        self.next_button = QPushButton("Next")
        close_button = QToolButton()
        close_button.setText("✕")
        close_button.setAutoRaise(True)
        close_button.setToolTip("Close (Esc)")
        self.replace_edit = QLineEdit()
        self.replace_edit.setPlaceholderText("Replace with")
        self.replace_button = QPushButton("Replace")
        self.replace_all_button = QPushButton("Replace All")

        find_row = QHBoxLayout()
        find_row.addWidget(QLabel("Find:"))
        find_row.addWidget(self.find_edit, 1)
        for widget in (self.case_box, self.count_label, self.prev_button, self.next_button, close_button):
            find_row.addWidget(widget)
        self.replace_row = QWidget()
        replace_layout = QHBoxLayout(self.replace_row)
        replace_layout.setContentsMargins(0, 0, 0, 0)
        replace_layout.addWidget(QLabel("Replace:"))
        replace_layout.addWidget(self.replace_edit, 1)
        replace_layout.addWidget(self.replace_button)
        replace_layout.addWidget(self.replace_all_button)
        outer = QVBoxLayout(self)
        outer.setContentsMargins(6, 4, 6, 4)
        outer.addLayout(find_row)
        outer.addWidget(self.replace_row)

        self._recount = QTimer(self)
        self._recount.setSingleShot(True)
        self._recount.setInterval(RECOUNT_MS)
        self._recount.timeout.connect(self._update_count)

        self.find_edit.textChanged.connect(self._search_as_typed)
        self.case_box.toggled.connect(self._search_as_typed)
        self.find_edit.returnPressed.connect(self.find_next)
        self.replace_edit.returnPressed.connect(self.replace_one)
        self.prev_button.clicked.connect(self.find_previous)
        self.next_button.clicked.connect(self.find_next)
        self.replace_button.clicked.connect(self.replace_one)
        self.replace_all_button.clicked.connect(self.replace_all)
        close_button.clicked.connect(self.close_bar)
        self.editor.document().contentsChanged.connect(self._on_text_edited)
        for edit in (self.find_edit, self.replace_edit):
            edit.installEventFilter(self)

    # --- open / close ----------------------------------------------------------

    def open_find(self) -> None:
        self._open(replace=False)

    def open_replace(self) -> None:
        self._open(replace=True)

    def _open(self, replace: bool) -> None:
        selected = self.editor.textCursor().selectedText()
        if selected and "\u2029" not in selected:  # single-line selections only
            self.find_edit.blockSignals(True)  # it is already selected in the editor
            self.find_edit.setText(selected)
            self.find_edit.blockSignals(False)
        self.replace_row.setVisible(replace)
        self.show()
        self.find_edit.setFocus()
        self.find_edit.selectAll()
        self._update_count()

    def close_bar(self) -> None:
        self.hide()
        self.editor.setFocus()

    def eventFilter(self, obj, event) -> bool:
        if event.type() == QEvent.Type.KeyPress:
            if event.key() == Qt.Key.Key_Escape:
                self.close_bar()
                return True
            if (obj is self.find_edit and event.key() in (Qt.Key.Key_Return, Qt.Key.Key_Enter)
                    and event.modifiers() & Qt.KeyboardModifier.ShiftModifier):
                self.find_previous()
                return True
        return super().eventFilter(obj, event)

    def keyPressEvent(self, event) -> None:
        if event.key() == Qt.Key.Key_Escape:  # focus on a button or the checkbox
            self.close_bar()
        else:
            super().keyPressEvent(event)

    # --- searching -------------------------------------------------------------

    def find_next(self) -> bool:
        return self._find(backward=False)

    def find_previous(self) -> bool:
        return self._find(backward=True)

    def _flags(self, backward: bool = False):
        flags = QTextDocument.FindFlag(0)
        if self.case_box.isChecked():
            flags |= QTextDocument.FindFlag.FindCaseSensitively
        if backward:
            flags |= QTextDocument.FindFlag.FindBackward
        return flags

    def _find(self, backward: bool) -> bool:
        needle = self.find_edit.text()
        if not needle:
            self.count_label.setText("")
            return False
        doc = self.editor.document()
        flags = self._flags(backward)
        found = doc.find(needle, self.editor.textCursor(), flags)
        if found.isNull():  # wrap around
            start = QTextCursor(doc)
            if backward:
                start.movePosition(QTextCursor.MoveOperation.End)
            found = doc.find(needle, start, flags)
        if not found.isNull():
            self.editor.setTextCursor(found)
        self._update_count()
        return not found.isNull()

    def _search_as_typed(self, *_args) -> None:
        """Re-search from the start of the current selection so typing extends the match."""
        cursor = self.editor.textCursor()
        cursor.setPosition(cursor.selectionStart())
        self.editor.setTextCursor(cursor)
        self._find(backward=False)

    def _matches(self) -> list[tuple[int, int]]:
        needle = self.find_edit.text()
        doc = self.editor.document()
        flags = self._flags()
        spans = []
        found = QTextCursor(doc)
        while needle:
            found = doc.find(needle, found, flags)
            if found.isNull():
                break
            spans.append((found.selectionStart(), found.selectionEnd()))
        return spans

    def _update_count(self) -> None:
        if not self.find_edit.text():
            self.count_label.setText("")
            return
        spans = self._matches()
        cursor = self.editor.textCursor()
        current = (cursor.selectionStart(), cursor.selectionEnd())
        if not spans:
            text = "No results"
        elif current in spans:
            text = f"{spans.index(current) + 1} of {len(spans)}"
        else:
            text = "1 match" if len(spans) == 1 else f"{len(spans)} matches"
        self.count_label.setText(text)

    def _on_text_edited(self) -> None:
        if self.isVisible():
            self._recount.start()

    # --- replacing -------------------------------------------------------------

    def replace_one(self) -> None:
        cursor = self.editor.textCursor()
        if cursor.hasSelection() and (cursor.selectionStart(), cursor.selectionEnd()) in self._matches():
            cursor.insertText(self.replace_edit.text())
            self.editor.setTextCursor(cursor)
        self._find(backward=False)

    def replace_all(self) -> int:
        needle = self.find_edit.text()
        if not needle:
            return 0
        doc = self.editor.document()
        flags = self._flags()
        replacement = self.replace_edit.text()
        count = 0
        found = QTextCursor(doc)
        block = QTextCursor(doc)
        block.beginEditBlock()  # the whole Replace All is one undo step
        try:
            while True:
                found = doc.find(needle, found, flags)
                if found.isNull():
                    break
                found.insertText(replacement)  # search resumes after the inserted text
                count += 1
        finally:
            block.endEditBlock()
        self._recount.stop()  # keep the "replaced" message instead of a recount
        self.count_label.setText(f"{count} replaced" if count else "No results")
        return count
```

Design notes:
- **Dark mode uses the Fusion style:** the native `windowsvista` style draws menus, buttons and scroll bars with the light Windows theme whatever the palette says. Light mode keeps `windowsvista` and its standard palette, so a forced Light theme on a dark system really is light.
- **Title bar:** a best-effort `DwmSetWindowAttribute(DWMWA_USE_IMMERSIVE_DARK_MODE = 20)` call also matches the Windows title bar to a forced theme. It is a silent no-op where unsupported.
- **No reload:** a theme change re-renders the preview from the buffer with `keep_scroll=True`. It never reloads from disk and never switches mode. In edit mode the editor is recolored, and the preview is rendered on the next switch to Preview.

````markdown
# MD Viewer

A Notepad-like Markdown viewer for Windows 10/11. Files open in a rendered
preview with GitHub-like styling that follows the Windows light/dark theme
(live), and View > Edit Mode turns the window into a plain-text editor with
structural completion and syntax-check underlines. The open file is watched:
the preview refreshes on its own when the file changes on disk.

## Running

```powershell
.venv\Scripts\python main.py [path\to\file.md]
```

You can also open files with File > Open... (`*.md *.markdown *.mdown *.txt`)
or by dragging one onto the window.

## Keyboard shortcuts

| Menu | Command | Shortcut |
| --- | --- | --- |
| File | New / Open... / Save / Save As... | Ctrl+N / Ctrl+O / Ctrl+S / Ctrl+Shift+S |
| File | Close / Exit | Ctrl+W / Alt+F4 |
| Edit | Undo / Redo | Ctrl+Z / Ctrl+Y |
| Edit | Cut / Copy / Paste / Select All | Ctrl+X / Ctrl+C / Ctrl+V / Ctrl+A |
| Edit | Find... / Replace... | Ctrl+F / Ctrl+H |
| View | Preview Mode / Edit Mode | Ctrl+P / Ctrl+E |
| View | Zoom In / Zoom Out / Restore Default Zoom | Ctrl+= / Ctrl+- / Ctrl+0 |
| Editor | Show completions | Ctrl+Space |

Edit commands work in Edit Mode only, except Copy, which also copies
selected text from the preview.

## Editing features

- Auto-close for `*`, `_`, backtick, `[`, `(`. Typing the closer steps over it,
  and Backspace between an empty pair removes both.
- Enter continues bullet, numbered (incremented) and quote lines; Enter on an
  empty item ends the list. No continuation inside code fences or tables.
- Completion popup on `#`, `|`, backtick, `>`, `-`, `*`, `_`, `[` and
  Ctrl+Space: heading levels, table separator/data rows, quote prefixes,
  code-fence languages, task-list items.
- Wavy underlines: red for an unclosed code fence, a table row with the wrong
  number of columns, or a table without a `|---|` row; orange for `#Heading`
  without a space, unbalanced `**` / `__`, or an odd number of backticks.
  Hover an underline for the message.

## Settings

Theme choice (View > Theme: System (auto) / Light / Dark), window position
and size, and preview zoom are stored in `%APPDATA%\MDViewer\settings.json`.
Delete that file to reset them.

## Known limitations

- Files are saved in the encoding they were opened with. If the text can no
  longer be represented in it (e.g. CJK text in a Windows-1252 file), MD Viewer
  offers to save as UTF-8 instead.
- Line endings are saved in the file's dominant style (CRLF if the file had
  any CRLF, else LF); mixed line endings are normalized to that style.
- Relative image paths are resolved for Markdown images and links; raw HTML
  `<img src="relative.png">` tags are not resolved.
- JavaScript in raw HTML never runs in the preview.
- Files above roughly 10 MB render slowly.
- Dark mode uses Qt's Fusion style, because the native `windowsvista` style
  cannot be darkened; light mode uses the native style.
